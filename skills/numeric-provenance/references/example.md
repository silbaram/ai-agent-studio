# 예시: 초반 상점 경제

이 문서는 태그 사용 예시다. 실제 게임 수치가 아니며, 아래 `[계산]` 출처 파일은 이 저장소에 없다.

## 수치 표

| 항목 | 값 | 출처 |
| --- | ---: | --- |
| 슬라임 처치 골드 | 5 | [가정: 장르 관례] |
| 회복 포션 가격 | 30 | [가정: 기획 의도 — 슬라임 6마리] |
| 첫 무기 구매 시점 | 4분 | [계산: sim/early-shop-run-001.json] |
| 1스테이지 평균 클리어 시간 | 7분 | [측정: playtest-2026-11-03 3명 평균] |

## 해석

- 첫 무기 구매 시점은 시뮬레이터가 위 두 가정값으로 계산한 결과다. 가정값이 바뀌면 다시 계산해야 한다.
- 클리어 시간은 3명 측정이라 표본이 작다. 결론 대신 "현재 관측값"으로 다룬다.
- `[가정]`이 2개 남아 있으므로 `--fail-on-assumed` 검사는 실패한다. 이 상태에서 "초반 경제 확정"이라고 판정하지 않는다.
